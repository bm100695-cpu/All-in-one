# All in One CBT Station Android client

This is the native Android container for the existing LMS website. It keeps login,
plans, order creation, payment verification, subscriptions, and portal filtering in
the existing application and server. The only native responsibility is Cashfree's
official Android UPI Intent journey.

## What it does

- Loads the existing portal in a protected WebView.
- After the server creates a Cashfree order, the portal offers **UPI apps** only
  inside this Android client.
- Cashfree's Android SDK discovers the UPI applications installed on the device and
  launches the user-selected one. No `upi://` link or app-specific deep link is
  generated by this project.
- Google Pay, PhonePe, and Paytm are shown only when their current official
  Android packages are installed. Selecting one passes Cashfree's corresponding
  SDK enum as the app priority; **Other UPI apps** deliberately uses Cashfree's
  full supported-app selector. Cashfree remains responsible for the final
  handoff and unavailable-app fallback.
- The SDK callback dispatches the order ID back to the portal; the existing backend
  verifies Cashfree status and activates the entitlement.
- Card and net-banking continue through the official Cashfree hosted checkout.

## Build

Open the `android` folder in Android Studio and build with the Android SDK installed.
For a staging portal, set a Gradle property rather than editing source:

```text
./gradlew assembleDebug -PportalUrl=https://staging.example.com
```

Do not add Cashfree credentials to the Android app. The current backend creates
orders and keeps Cashfree secrets server-side. Before releasing, confirm that the
Cashfree merchant account has UPI enabled and test with the merchant's sandbox
account on a physical Android device with installed UPI applications.
