# SSC CGL verified-paper intake

This folder deliberately contains no recreated or scraped SSC CGL question papers.

SSC notices confirm release of final answer keys and candidate-specific question papers, but the paper downloads are normally available through a candidate login for a limited window. The repository has no source PDF, response sheet, answer key, or licence record that can substantiate a complete paper.

Use the isolated SSC CGL importer only after collecting a legally reusable source package. A paper must supply:

- unique `sourcePaperKey` (for example `SSC-CGL-2024-T1-YYYY-MM-DD-S1`);
- year, date only when verified, shift only when verified, tier and paper type;
- source URL/reference and verified official final answer key;
- a complete question set matching its specific pattern;
- complete options, answer key, detailed solution, and diagrams where required.

Unverified or incomplete imports must remain drafts. The publish validator is available at `GET /api/ssc-cgl/admin/papers/:testId/validate` for administrators.
